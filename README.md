# Ziyang Wang — Personal Portfolio

国际化金融行业个人品牌主页 | International Finance Personal Brand Website

## 预览

在浏览器中直接打开 `index.html`，或使用本地服务器：

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

然后访问 `http://localhost:8080`

## 项目结构

```
个人简历/
├── index.html          # 主页面
├── css/
```

## 功能

- 中英文一键切换（EN / 中文）
- 玻璃拟态（Glassmorphism）设计
- 滚动动画、悬浮效果、导航栏变化
- 响应式布局（手机 / 平板 / 桌面）

## 技术栈

HTML5 · CSS3 · Vanilla JavaScript
